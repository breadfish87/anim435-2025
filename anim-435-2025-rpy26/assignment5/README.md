# Object Creation and Scatter Script

## Usage

This script is meant to be run from a terminal, you will be asked to enter a **whole positive number.** The script will also create an .ma file at the same directory from where the script is located.

## Steps

- In a terminal: mayapy "filename.py"
- Enter the prompted input
- If errors occur: Look at error messages to adjust input

## Wanrings

- If a large input is entered it may take a moment to run the script
- The input must be a **whole number**
